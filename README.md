# Room Expense Sharing Calculator

## About
This is a simple Python project that calculates the amount each person needs to pay for shared room or flat expenses.

## Features
- Takes rent as input
- Takes food expenses as input
- Calculates electricity bill
- Divides the total expense among people
- Shows the amount each person needs to pay

## Technologies Used
- Python

## How It Works
The user enters:
- Rent
- Food expenses
- Electricity units
- Charge per unit
- Number of people

The program calculates the electricity bill and divides the total expenses equally among all people.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Run the Python file.
4. Enter the required details.
